# 设计文档

> 本文档描述「漫画灰个人博客」的定位、架构、数据模型与设计规范，与当前实现保持一致。

## 1. 定位与目标

一个**偏求职 + 技能展示（作品集导向）**的个人博客，中文为主，兼顾生活记录。面向两类读者：

- **潜在雇主 / 面试官**——快速了解「我是谁、会什么、做过什么、在找什么工作」。
- **自己与朋友**——记录求职心路与生活。

站点围绕四个问题组织内容：

| 问题 | 对应模块 |
|---|---|
| 我是谁 | 首页定位、关于我 |
| 我会什么 | 技能栈、作品集 |
| 我想去哪 | 求职状态、求职感悟 |
| 我在做什么 | 博客文章、生活相册 |

## 2. 技术选型

| 层 | 选型 | 说明 |
|---|---|---|
| Web 框架 | Django 5 | 自带 Admin、ORM、迁移、表单校验 |
| 数据库 | SQLite | 零运维，可平滑切换 PostgreSQL |
| 文章内容 | Markdown + Python-Markdown + Pygments | 服务端渲染，代码高亮 |
| 模板 | Django Templates | 服务端渲染，不引入前端框架 |
| 样式 | 手写 CSS（CSS 变量） | 深浅色主题，无 Node 构建链 |
| 图片 | Pillow | ImageField 依赖 |
| 搜索 | `__icontains` | 预留升级 FTS5 / PostgreSQL 全文索引 |
| 评论 | 自建 + 后台审核 | 存自身数据库，蜜罐防垃圾 |

## 3. 数据模型

```
Profile（个人资料，单例）      姓名 / 定位 / 头像 / 简介 / 所在地 / 邮箱 / 电话 / GitHub / 博客链接
SiteSetting（站点配置，单例）   站点名 / 描述 / 页脚 / 求职状态 / 目标方向 / 简历文件 / 求职感悟分类 slug

Category（分类）              名称 / slug / 描述 / 排序
Tag（标签）                  名称 / slug
Post（文章）                 标题 / slug / 摘要 / Markdown 原文 / 渲染 HTML / 封面 / 状态 / 精选 / 浏览量 / 分类 / 标签 / 发布时间
Comment（评论）              所属文章 / 父评论（支持回复）/ 昵称 / 邮箱 / 内容 / 审核状态 / 时间

Project（项目）              名称 / slug / 简介 / Markdown 详情 / 技术栈 / 封面 / 链接 / GitHub / 排序 / 精选
Skill（技能）               名称 / 分类 / 熟练度(1-5) / 说明 / 排序
CareerTimeline（经历）       类型(工作/教育/里程碑) / 机构 / 角色 / 起止时间 / 描述 / 排序

Album（相册）               名称 / slug / 封面 / 描述 / 排序
GalleryPhoto（照片）         所属相册 / 标题 / 图片 / 描述 / 拍摄时间 / 是否公开 / 排序
```

## 4. 页面与路由

| 页面 | URL | 要点 |
|---|---|---|
| 首页 | `/` | Hero 定位、技能亮点、精选项目、求职状态、最新文章 |
| 关于我 | `/about/` | 自我介绍、经历时间线、技能栈、联系方式 |
| 博客列表 | `/blog/` | 分类 / 标签筛选、分页、搜索入口 |
| 文章详情 | `/blog/<slug>/` | Markdown 正文 + 代码高亮、上一篇 / 下一篇、评论 |
| 作品集 | `/projects/` | 项目卡片、技术栈筛选 |
| 项目详情 | `/projects/<slug>/` | 项目背景、职责、成果、链接 |
| 求职与简历 | `/career/` | 求职状态、在线简历、求职感悟文章 |
| 在线简历 | `/resume/` | 复用个人资料 / 技能 / 经历 / 项目，可打印导出 PDF |
| 生活相册 | `/gallery/` | 相册封面、图片墙、灯箱（隐蔽入口） |

## 5. 设计规范

### 5.1 色彩

以「漫画灰」为基调：暖灰纸白 + 近黑，灰阶分层；点缀色用**朱砂红**（呼应黑白漫画的一点红）。支持浅色 / 深色两套主题。

| 用途 | 浅色 | 深色 |
|---|---|---|
| 页面底色 | `#fafaf8` | `#1c1b19` |
| 浅色区块 | `#f2f1ee` | `#26241f` |
| 描边 / 分隔 | `#e6e4df` | `#33302a` |
| 次级文字 | `#8f8c85` | `#8b877e` |
| 正文 | `#403d37` | `#d4d0c7` |
| 标题 / 强调 | `#1a1917` | `#f2efe9` |
| 点缀（朱砂红） | `#c0503a` | `#d96b4e` |

### 5.2 字体

- 中文正文：`-apple-system, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`
- 代码 / 数字：`"JetBrains Mono", ui-monospace, "SF Mono", Consolas, monospace`
- 正文 16px / 行高 1.75；标题字重 700。

### 5.3 间距、圆角与阴影

- 8px 网格间距；卡片圆角 10px、按钮 6px。
- 阴影分层（`--shadow-sm / md / lg`），深色模式加重。

### 5.4 动效

- 统一缓动曲线 `cubic-bezier(0.22, 1, 0.36, 1)`。
- 滚动入场（IntersectionObserver + 错峰延迟）、卡片 hover 上浮 / 图片缩放 / 描边变红、按钮 hover、阅读进度条、回到顶部。
- `prefers-reduced-motion` 下关闭所有动画。

## 6. 交互细节

- **星空加载页**：进入时全屏 Canvas 星空（视差 + 光标星座连线 + 流星 + 光标节点），加载完成后点击「进入」，会话内只出现一次；无 JS / 已进入时直接跳过。
- **主题切换**：顶栏太阳 / 月亮按钮，写入 `localStorage`，首次跟随系统 `prefers-color-scheme`，避免闪烁。
- **评论**：含链接的评论进入待审核，其余直接通过；蜜罐字段拦截机器人；后台可批量审核 / 删除。
- **相册灯箱**：点击放大，左右方向键 / Esc 切换与关闭。
- **搜索**：标题 / 摘要 / 正文 / 标签模糊匹配，命中词用 `<mark>` 高亮。

## 7. 部署

- **VPS**：Gunicorn + Nginx + SQLite，适合长期运营。
- **PaaS**：Railway / Render / Fly.io 一键部署。
- 媒体文件本地存储，可后续接入对象存储（S3 / OSS）。
